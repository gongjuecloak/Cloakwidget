# MES 转换工具

把鼎新 ERP 导出的文件转成 MES 可导入的格式。**完全离线运行，数据不上传任何服务器。**

打开程序先选模块，两个模块互相独立：

| 模块 | 输入 | 输出 |
|---|---|---|
| **物料档案** | 鼎新物料档（`MB001` ~ `MB254`） | MES「物料档案导入模板」单表 |
| **订单 / 工单** | 鼎新订单档 + 製令（工单）档 | MES「销售订单主表 / 销售订单明细 / 工单」三张表 |

当前版本：**v1.6.0**

---

## 一、怎么用

### 模块一：物料档案（三步）

1. **选源文件**：鼎新 ERP 导出的物料档。支持 `.xlsx`、`.xls`（老格式）、`.csv`。
   - **可以一次选多个文件**（或整批拖进窗口），工具会按列名对齐后**合并成一份结果**；
   - 选了哪几个文件，卡片下方会列出来，点文件名右侧的 **×** 可以重新选。
2. **选模板**：MES 的「物料档案导入模板」（.xlsx）。
3. **点「开始转换」**：转换过程中会显示进度（已处理多少行 / 共多少行）。完成后可下载结果。

> CSV 文件不用管编码，工具会自动识别 UTF-8 / GBK；分隔符（逗号、制表符、分号）也自动判断。
> 文件的真实格式按**内容**判断，扩展名写错也能认出来。

### 模块二：订单 / 工单（两步，两个文件都可选）

1. **选订单文件**（可选）：鼎新导出的订单档 —— 生成销售订单主表与明细。
2. **选工单文件**（可选）：鼎新导出的製令（工单）档 —— 生成工单表。

> 两个文件**至少给一个**。同时给会一次生成三张表，且工单的「销售订单行号」会自动去订单明细里匹配回填。
> 和物料档案一样，这两处也支持一次选多个文件合并。

这一模块由原来的 Python 版工具重写而来，业务口径完全一致（表头自动识别、简繁混用表头、跳过报表标题行、过滤小计/合计行、行号回填、打标判定）。

结果文件保存在程序目录的 `out\` 文件夹：

- 物料档案：`MES物料档案_20261007_120301.xlsx`
- 订单工单：`订单工单_20261007_120301.xlsx`

按日期时间命名，**不会重名、不会覆盖**。

## 二、程序常驻右下角

程序启动后常驻系统托盘（右下角）。**关掉浏览器标签页不会退出程序。**

右键托盘图标，菜单自上而下是：

| 菜单项 | 效果 |
|---|---|
| 最近转换：`10-07 14:32 · 288 行 · 3 问题` | 只读摘要，灰显不可点，一眼看出上次转了多少行、有几个问题 |
| 打开界面 | 用默认浏览器打开操作界面 |
| 打开输出文件夹 | 直接打开 `out\` |
| 重启程序 | 改过局域网等设置后，不用手动关掉再开 |
| 检查更新… | 打开项目的发布页（**不会自动下载安装**） |
| 退出 | 彻底关闭程序 |
| 双击托盘图标 | 打开界面 |

> 要彻底关闭程序，请用托盘右键菜单的「退出」。
> 重复双击 exe 不会开出第二个程序（已做单实例检测）。

## 三、转换后的问题怎么看

转换完成后，结果区会给出：

- **占比小图**：本次输出里「正常行 / 告警 / 错误」各占多少，一眼看清数据质量；
- **问题明细**：逐条列出在哪个字段、第几行。

**物料档案**会检查：

| 检查项 | 说明 |
|---|---|
| 物料编码重复 | 同一份源档里编码出现两次以上，会指出编码、首次出现的位置和重复位置 |
| Excel 错误值 | 单元格是 `#N/A`、`#REF!`、`#VALUE!`、`#DIV/0!` 这类错误值时逐条点名 |
| 字典里没有的值 | 如物料类型 `111` 不在字典表里 |
| 单位不在档案里 | 源文件的单位写法 MES 单位档案里没有 |
| 模板被换过 | 见下方「模板变化告警」 |

**订单 / 工单**会检查：

| 检查项 | 说明 |
|---|---|
| 明细重复 | 默认按「订单编号 + 产品编码」组合查重，同一单里同一个料号出现多次会点名 |
| 工单号重复 | 工单表按「工单号」查重 |
| 必填列为空 | 输出的必填列没有值 |
| 数量不是数字 | 数量列填了非数字内容 |

> 查重键可以在配置中心里改（能配多列组合键；把某一项的键留空即关闭该张表的查重）。

**模板变化告警**：第一次转换时，工具会把 MES 模板的表头记成「基准」。以后如果模板被换过
（加了列 / 删了列 / 调了顺序），转换时会在结果里提醒。这套基准可以在配置中心「系统」页签里
清除并重新记录。

这些提示**不影响文件生成**，但可能导致导入 MES 失败，建议先处理。

「最近转换」列表里每行都有「查看问题」按钮，**重启程序后依然能翻回任意一次的问题明细**。
列表下方还有**转换统计**面板：按天汇总最近 14 天的转换次数、累计输出行数、零问题次数等。

## 四、界面语言

支持 **简体中文 / 繁體中文 / Tiếng Việt / English**，右上角切换。提示信息、日志、托盘菜单都会跟随。

顶部「? 使用说明」是内置图文教程，联系人可以直接看。

## 五、配置中心（管理员）

点首页的「配置中心」入口（或右上角「⚙ 配置」）进入。配置和日常操作是分开的 ——
操作页面只负责选文件、转换、看结果，不用一边选文件一边维护字段映射。

配置中心用页签切换：**物料档案 / 订单·工单 / 系统**。

### 物料档案页签

| 功能 | 说明 |
|---|---|
| 字段映射 | 每一列怎么填：直接复制 / 字典翻译 / 固定值 / 条件填充 / 关键词判断 / 关键词映射 / 单位翻译 / 多条件判断。**表格行序就是输出列顺序，可拖动左侧把手调整** |
| 字段表工具条 | 按目标列 / 源列**搜索**、按**填充方式分组**筛选，并显示「显示 N / M 行」 |
| 单位翻译表 | 原符号 → 中文单位名，如 `kg → 千克` |
| 字典表 | 代码 → 中文，如 `110 → 成品` |
| 允许值清单 | 某列只允许哪些值，不在清单里会在预检中告警 |
| 配置备份 | 每次保存自动留一份，改坏了可还原 |
| **配置档** | 把当前配置存成命名档案（如「A厂-模板3」），不同工厂 / 模板一键载入 |
| **值域表 CSV** | 把字典表 / 单位表导出成 CSV，交给懂业务的人改完再导回，不用碰 JSON |

> **保存前会先给你看一遍改动**：点「保存配置」先弹出「确认配置变更」，逐条列出这次会新增 /
> 删除 / 修改什么，确认无误再点「确认保存」；点「取消」什么都不会写入。

### 订单 / 工单页签

| 功能 | 说明 |
|---|---|
| 字段映射 | 三张表各自一张「输出列 ⇄ 源列 + 默认值」表格，**表格行序就是输出列顺序** |
| 打标判定 | 产品编码以哪些前缀开头算「需要打标」 |
| 运行选项 | 表头是否带 `*` 必填星号、是否自动匹配销售订单行号、是否过滤合计行、是否做数据校验 |
| 表头别名表 | 源档表头五花八门时靠它识别（已做简繁归一，写简写繁都认） |
| 配置备份 | 保存前自动备份上一份 |

> 两套配置互不影响：物料档案是 `mapping.json`，订单/工单是 `orders.json`。
> 配置档：点「另存为配置档」取名保存；切换时选中 →「载入」→ 点「保存配置」生效。
> 值域表：**导入会按 CSV 内容整体替换**字典表与单位表，所以要先导出全量再改。

### 系统页签

程序**自身**怎么运行，跟字段映射无关，三张卡片：

| 卡片 | 说明 |
|---|---|
| 局域网访问 | 默认只监听本机（`127.0.0.1`），同事访问不到。打开「允许局域网访问」并保存后重启程序，同一局域网的同事用浏览器即可访问；页面会给出可访问的地址 |
| 访问口令 | 设了口令后，除探活外的所有接口都要先验证；口令**只存加盐哈希，不存明文**。打开界面时若被拦，会弹框让你输口令 |
| 开机自启 | 勾选「开机自动运行」后，登录 Windows 即在右下角托盘运行、不弹浏览器。只写当前用户的启动项，**不需要管理员权限** |

下面还有两块：

- **物料档案模板基准**：显示当前记了几列、什么时候记的；「清除基准」会让下次转换重新记录。
- **诊断与更新**：「生成排障包」打一个 zip（日志 + 配置 + 环境信息，口令已脱敏）方便发给维护的人；
  「检查更新」查一下有没有新版本（只提示，不自动下载）。

## 六、关于基本单位

MES 单位档案里，「PCS」和「件」是**两个不同单位**。本工具的口径是
**源文件里合法的单位名原样保留**（PCS 保持 PCS、SET 保持 SET），
只对「档案里不存在的写法」做归一：

| 源文件写法 | 转换结果 | 原因 |
|---|---|---|
| `pcs`（小写） | `PCS` | 档案里只有大写 PCS |
| `PCSQ` | `PCS` | 拼写错误 |
| `捲`（繁体） | `卷` | 档案里是简体「卷」 |
| `KG` / `kg` | `千克` | 档案里没有 KG，只有「千克」 |
| `M` / `m` | `米` | 档案里没有 M，只有「米」 |

## 七、出问题了怎么办

| 现象 | 处理 |
|---|---|
| 双击 exe 没反应 | 看右下角托盘图标——界面已在后台运行；或已有一个实例在跑 |
| 转换失败 | 下方「转换日志」有详细原因 |
| 需要排查 | 配置中心 →「系统」→「生成排障包」，把打出来的 zip 发给制作者（口令等敏感信息已自动脱敏） |
| 想看版本 / 路径 | 顶部「关于」可看到版本、配置文件、日志文件、输出目录的完整路径 |

## 文件说明

| 文件 / 目录 | 说明 |
|---|---|
| `物料档案转换工具.exe` | 主程序（单文件即可运行） |
| `webui.html` | 界面文件（放在 exe 同级可覆盖内嵌版本，改界面不用重编译） |
| `mapping.json` | 物料档案模块的转换配置 |
| `orders.json` | 订单 / 工单模块的转换配置（首次运行自动生成） |
| `tpl_baseline.json` | MES 模板表头基准（第一次转换后自动生成） |
| `sys_settings.json` | 系统页签的设置（局域网开关、口令哈希，首次修改后自动生成） |
| `out\` | 转换结果与日志 |
| `out\reports\` | 每次转换的完整报告（问题明细，保留最近 100 份） |
| `logs\` | 程序运行日志（按天切分） |
| `backup\` | 配置备份 |
| `configs\` | 命名配置档（物料档案模块） |

> 环境要求：Windows 10 / 11 或 Windows Server 2012 R2 及以上，无需安装任何运行库。

## 命令行用法（可选）

| 参数 | 说明 |
|---|---|
| `-cli` | 无界面模式，按 `mapping.json` 转物料档案 |
| `-order <文件>` / `-work <文件>` | 走订单 / 工单模块 |
| `-out <路径>` | 指定输出文件 |
| `-lang zh\|zht\|vi\|en` | 提示语言 |
| `-port 8731` | 界面端口 |
| `-nobrowser` | 启动时不自动开浏览器（适合开机自启） |

界面也支持深链：`http://127.0.0.1:8731/?view=orders&lang=en`
