# MES 转换工具

把鼎新 ERP 导出的文件转成 MES 可导入的格式。**完全离线运行，数据不上传任何服务器。**

打开程序先选模块，两个模块互相独立：

| 模块 | 输入 | 输出 |
|---|---|---|
| **物料档案** | 鼎新物料档（`MB001` ~ `MB254`） | MES「物料档案导入模板」单表 |
| **订单 / 工单** | 鼎新订单档 + 製令（工单）档 | MES「销售订单主表 / 销售订单明细 / 工单」三张表 |

当前版本：**v1.3.0**

---

## 一、怎么用

### 模块一：物料档案（三步）

1. **选源文件**：从鼎新 ERP 导出的物料档（.xlsx）。也可以直接把文件拖进窗口。
2. **选模板**：MES 的「物料档案导入模板」（.xlsx）。
3. **点「开始转换」**：转换过程中会显示进度（已处理多少行 / 共多少行）。完成后可下载结果。

### 模块二：订单 / 工单（两步，两个文件都可选）

1. **选订单文件**（可选）：鼎新导出的订单档 —— 生成销售订单主表与明细。
2. **选工单文件**（可选）：鼎新导出的製令（工单）档 —— 生成工单表。

> 两个文件**至少给一个**。同时给会一次生成三张表，且工单的「销售订单行号」会自动去订单明细里匹配回填。

这一模块由原来的 Python 版工具重写而来，业务口径完全一致（表头自动识别、简繁混用表头、跳过报表标题行、过滤小计/合计行、行号回填、打标判定）。

结果文件保存在程序目录的 `out\` 文件夹：

- 物料档案：`MES物料档案_20261007_120301.xlsx`
- 订单工单：`订单工单_20261007_120301.xlsx`

按日期时间命名，**不会重名、不会覆盖**。

## 二、程序常驻右下角

程序启动后常驻系统托盘（右下角）。**关掉浏览器标签页不会退出程序。**

| 操作 | 效果 |
|---|---|
| 右键托盘图标 | 打开界面 / 打开输出文件夹 / **退出** |
| 双击托盘图标 | 打开界面 |

> 要彻底关闭程序，请用托盘右键菜单的「退出」。
> 重复双击 exe 不会开出第二个程序（已做单实例检测）。

## 三、预检：转换后的问题怎么看

转换完成后，下方会列出发现的问题：

**物料档案**：物料编码重复、字典里没有的值（如物料类型 `111`）、单位不在 MES 单位档案里。

**订单 / 工单**：必填列为空、数量不是数字、输出的必填列没有值。

这些**不影响文件生成**，但可能导致导入 MES 失败，建议先处理。

「最近转换」列表里每行都有「查看问题」按钮，**重启程序后依然能翻回任意一次的问题明细**。

## 四、界面语言

支持 **简体中文 / 繁體中文 / Tiếng Việt / English**，右上角切换。提示信息、日志、托盘菜单都会跟随。

## 五、高级设置（管理员）

展开「高级设置」，**全部是表单填写，不需要写代码**。

### 物料档案模块

| 功能 | 说明 |
|---|---|
| 字段映射 | 每一列怎么填：直接复制 / 字典翻译 / 固定值 / 条件填充 / 关键词判断 / 关键词映射 / 单位翻译 / 多条件判断 |
| 单位翻译表 | 原符号 → 中文单位名，如 `kg → 千克` |
| 字典表 | 代码 → 中文，如 `110 → 成品` |
| 允许值清单 | 某列只允许哪些值，不在清单里会在预检中告警 |
| 配置备份 | 每次保存自动留一份，改坏了可还原 |
| **配置档** | 把当前配置存成命名档案（如「A厂-模板3」），不同工厂 / 模板一键载入 |
| **值域表 CSV** | 把字典表 / 单位表导出成 CSV，交给懂业务的人改完再导回，不用碰 JSON |

### 订单 / 工单模块

| 功能 | 说明 |
|---|---|
| 字段映射 | 三张表各自一张「输出列 ⇄ 源列 + 默认值」表格，**表格行序就是输出列顺序** |
| 打标判定 | 产品编码以哪些前缀开头算「需要打标」 |
| 运行选项 | 表头是否带 `*` 必填星号、是否自动匹配销售订单行号、是否过滤合计行、是否做数据校验 |
| 表头别名表 | 源档表头五花八门时靠它识别（已做简繁归一，写简写繁都认） |
| 配置备份 | 保存前自动备份上一份 |

> 两套配置互不影响：物料档案是 `mapping.json`，订单/工单是 `orders.json`。
> 配置档：点「另存为配置档」取名保存；切换时选中 →「载入」→ 点「保存配置」生效。
> 值域表：**导入会按 CSV 内容整体替换**字典表与单位表，所以要先导出全量再改。

## 六、关于基本单位

MES 单位档案里，「PCS」和「件」是**两个不同单位**。本工具的口径是
**源文件里合法的单位名原样保留**（PCS 保持 PCS、SET 保持 SET），
只对「档案里不存在的写法」做归一：

| 源文件写法 | 转换结果 | 原因 |
|---|---|---|
| `pcs`（小写） | `PCS` | 档案里只有大写 PCS |
| `PCSQ` | `PCS` | 拼写错误 |
| `捲`（繁体） | `卷` | 档案里是简体「卷」 |
| `KG` / `kg` | `千克` | 档案里没有 KG，只有「千克」 |
| `M` / `m` | `米` | 档案里没有 M，只有「米」 |

## 七、出问题了怎么办

| 现象 | 处理 |
|---|---|
| 双击 exe 没反应 | 看右下角托盘图标——界面已在后台运行；或已有一个实例在跑 |
| 转换失败 | 下方「转换日志」有详细原因 |
| 需要排查 | 顶部「关于」可看到版本、配置文件、日志文件、输出目录的完整路径；把 `logs\server_日期.log` 发给制作者 |

## 文件说明

| 文件 / 目录 | 说明 |
|---|---|
| `物料档案转换工具.exe` | 主程序（单文件即可运行） |
| `webui.html` | 界面文件（放在 exe 同级可覆盖内嵌版本，改界面不用重编译） |
| `mapping.json` | 物料档案模块的转换配置 |
| `orders.json` | 订单 / 工单模块的转换配置（首次运行自动生成） |
| `out\` | 转换结果与日志 |
| `out\reports\` | 每次转换的完整报告（问题明细，保留最近 100 份） |
| `logs\` | 程序运行日志（按天切分） |
| `backup\` | 配置备份 |
| `configs\` | 命名配置档（物料档案模块） |

> 环境要求：Windows 10 / 11 或 Windows Server 2012 R2 及以上，无需安装任何运行库。

## 命令行用法（可选）

| 参数 | 说明 |
|---|---|
| `-cli` | 无界面模式，按 `mapping.json` 转物料档案 |
| `-order <文件>` / `-work <文件>` | 走订单 / 工单模块 |
| `-out <路径>` | 指定输出文件 |
| `-lang zh\|zht\|vi\|en` | 提示语言 |
| `-nobrowser` | 启动时不自动开浏览器（适合开机自启） |

界面也支持深链：`http://127.0.0.1:8731/?view=orders&lang=en`
