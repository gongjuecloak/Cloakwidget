      配置中心
      
      
      两个模块的字段映射与规则都在这里维护。选文件、转换这些日常操作在各自的模块页面完成，这里只改配置。
      
    
      
    
      
      
      
      
    
      

    
    
      
      
      以下为字段映射配置，仅管理员维护。普通用户无需修改。所有设置都以表单填写，无需写代码。
      
      
      
        
        
      
      
      
      
        
        
        
        
        
        
      
      
      
      

      
      配置档（多套配置）
        把当前配置存成一份命名档案，不同工厂 / 模板一键载入
      
      
      
        
        
        
        
      
      

      
      值域表（导出给业务维护）
        把字典表 / 单位表导出成 CSV，交给懂业务的人改，再导回来，不用碰 JSON
      
      
      
        
        
        
      
      

      
      配置备份
        每次保存都会自动留一份备份，改坏了可以还原
      
      
      
        
        
        
      
      

      
      字段映射
        每一行 = 一个目标列怎么填
      
      
      
        
      
          目标列源列(MBxxx)
          填充方式参数设置
          说明
        
      
        
      
      
      
      

      
      单位翻译表
        左边填原符号，右边填中文单位名，例如 kg → 千克
      
      
      
        
      原符号 / 原单位翻译为
      
        
      
      
      

      
      字典表（原值 → 翻译）
        把源文件里的代码翻译成人能看懂的中文，例如 110 → 成品
      
      
      
      

      
      允许值清单
        某列的值不在清单里时，预检会告警（不改写数据）。例如「基本单位」只允许 MES 单位档案里的单位名
      
      
      
      
    
      

    
    
      
      
      订单模块的字段映射与判定规则。所有设置都以表单填写，无需写代码。
      

      
      
        
        
      
      
      
      

      
      字段映射
        每行 = 一个输出列：源列（可留空表示不导出）+ 源档为空时填入的默认值。表格行序就是输出列顺序。
      
      
      

      
      打标判定
        产品编码以任一前缀开头 → 「是」，否则「否」
      
      
      

      
      运行选项
      
      
      

      
      表头别名表
        源档表头五花八门时靠它识别。匹配时已做简繁归一，写简写繁都认。
      
      
      
    
      

    
    
      
      
      程序自身的运行方式：谁能访问、开机是否自动启动、MES 模板有没有变、出问题怎么取证。与字段映射无关；涉及监听的改动需要重启程序。
      

      
      访问与安全
        默认只监听本机 127.0.0.1，同事访问不到。开启局域网后建议同时设一个口令。
      
      
      
        
      
          
      局域网访问—
      
          
      打开后，同一局域网内的同事用浏览器即可访问本工具（改完需重启程序生效）。
      
          
      
            
            
          
      
          
      
        
      
        
      
          
      访问口令—
      
          
      设了口令后，除探活外的所有接口都要先验证；口令只存加盐哈希，不存明文。
      
          
      
            
            
            
            
          
      
        
      
        
      
          
      更新源—
      
          
      选择从哪里获取新版本。默认自动：优先走镜像，镜像不可达时回退 GitHub。
      
          
      
            
            
          
      
          
      
        
      
        
      
          
      开机自启—
      
          
      登录 Windows 后自动在右下角托盘运行，不弹浏览器。只写当前用户的启动项，不需要管理员权限。
      
          
      
            
            
          
      
          
      
        
      
      
      

      
      物料档案模板基准
        第一次转换会把 MES 模板的表头记下来；以后模板被换过（加列 / 删列 / 调顺序）转换时会告警。
      
      
      
        —
        
        
      
      

      
      诊断与更新
        出问题时打一个排障包（日志 + 配置 + 环境信息，口令已脱敏），发给维护的人即可。程序不会自动下载更新。
